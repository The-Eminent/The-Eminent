### 🚀 Projects I'm proud of

**🔥 IgnisAI: Wildfire Prediction System**
Real-time monitoring that ingests satellite and weather data and runs Gradient Boosting models to predict fire spread, delivering predictions in under 200ms with probabilistic overlays for rapid response.
`React` `Python` `TensorFlow` `MongoDB` `Scikit-learn` `Mapbox GL JS`

**🔎 Elastic RAG Assistant**
A hybrid RAG system that ingests Google Drive PDFs, chunks them heading-aware, and serves grounded, cited answers via an on-device LLM, combining ELSER, sparse/dense retrieval, and BM25 fusion.
`Python` `Elasticsearch` `FastAPI` `Streamlit` `Ollama`

**🔄 CodeSyncronix**
A real-time collaborative coding platform with live code synchronization for multiple developers, cutting manual code-sharing overhead by 50%.
`React.js` `Node.js` `Socket.io`
